# 更新日志

## 2.2.0 — 任务方案库与标签分类

**新功能：任务可以归类、下次直接复用**
- **任务方案**：把一整套任务（版本目录、场景、任务、目标条数、历史别名、目录名、标签）存成命名方案，保存在配置库里。
  - 另存为方案：保存的是编辑器里**当前**的内容（包括还没点“保存任务”的修改），不改变当前下载配置。
  - 载入方案有两种方式：**替换**当前配置，或**追加**（只添加当前没有的任务，已有任务和条数不变；与现有任务冲突的会被跳过并告知原因）。
  - 载入时可只取带某些**标签**的任务。
  - 重命名、用当前内容覆盖、删除；**导出 / 导入** JSON 文件，可在不同机器之间共享；导入同名时自动加序号，不会覆盖。
  - 首次启动会把初始任务自动存成方案“初始配置”。
- **标签**：每个任务可以有多个标签（逗号分隔，一个任务最多 12 个、每个最长 24 字符）。
  - 任务页：按标签筛选；对筛选出的任务**批量设置目标条数**；新增任务时自动带上当前筛选的标签。
  - 概览页：任务名下显示标签，筛选框也能按标签搜索。
  - 标签只是分类用的元数据，**下载器不读取**，不影响下载行为。
- 配置库升级到 schema 2（任务增加 `tags` 列，新增 `plans` 表）。旧配置库打开时自动升级，数据保留。
- 新增接口：`GET/POST /api/plans`、`GET/PUT/DELETE /api/plans/<id>`、`POST /api/plans/<id>/apply`、`GET /api/plans/<id>/export`、`POST /api/plans/import`。

**修复**
- 在输入框里输入后立刻点击按钮，点击偶尔“丢失”：失焦触发的重绘会在鼠标按下和松开之间替换掉按钮。
  现在内容没变就不重绘（标签条、概览各区块、方案列表）。
- 导入方案文件会让任务编辑器被误判为“有未保存的修改”：现在只有编辑器本身的输入才算。

**文档**：新增 `docs/` 开发文档——`DEVELOPMENT.md`（架构、模块、核心流程、状态机、跨平台、前端、测试、扩展配方、调试手册）、`API.md`（全部 HTTP 接口）、`DATA.md`（表结构、设置项、JSON 格式、目录布局、备份与重置）。

**测试**：98 → 117 个（新增标签、方案存储、过滤与合并、旧库升级、方案接口等）。

## 2.1.0 — 整体梳理与加固

**修复（会改变行为的，请留意）**
- **历史别名任务的选条顺序**：别名并入当前任务后，现在在任务内按 `create_time` 全局排序再“取最早的 N 条”。
  之前 SQL 按原任务名分组排序，会先吃光排在前面的那个别名下的数据。只影响**尚未下载**的数据；已下载的先被计入，不受影响。
- **质量状态为空的数据**：原 SQL 的 `NOT IN` 会因 NULL 语义悄悄丢掉 `quality_status` 为空的数据。默认行为保持不变（仍然排除），
  但现在是一个明确的设置项“包含质量状态为空的数据”（参数页），需要时可开启。
- **本地已有完整数据时不再访问 MinIO**：此前即使本地已有，仍会先列一次 MinIO 目录，MinIO 故障时会被记成失败。现在先查本地。
- **PostgreSQL 连不上**：给出明确的中文提示（并指引到“连接”页），不再打印堆栈；允许空密码（trust 认证）尝试连接；
  去掉了已经过时的“请在脚本开头填写 PG_PASSWORD”检查。
- 配置 / 环境类错误（MinIO 未配置、磁盘未挂载等）统一只打印原因，不打印堆栈。

**安全**
- 写接口必须是 `application/json`，浏览器带 `Origin` 时必须同源：防止别的网页借你的浏览器调用本机控制台（CSRF）。
- 没设访问口令时，`Host` 必须是 localhost / 127.0.0.1 / ::1：防 DNS 重绑定。
- 口令错误 8 次（5 分钟内）后锁定 60 秒（429 + Retry-After）；没带口令不计入失败。
- 页面与接口增加 `X-Frame-Options`、`X-Content-Type-Options`、`Referrer-Policy`、CSP、`Cache-Control: no-store`。
- 新增 `/healthz`（无需口令，不含配置信息）供监控使用。

**稳定性与性能**
- 配置库读取改用只读事务（WAL 下不被写入阻塞），新增一次性一致快照 `snapshot()`，不会读到“任务是新的、磁盘还是旧的”。
- 状态库只读连接改用 `Path.as_uri()`，Windows 下路径含空格 / 中文 / 盘符也能正确打开。
- 空闲时进度统计缓存放宽到 15 秒（要逐条检查本地目录是否存在）；下载中仍为 4 秒，正在下载的明细每次实时读取。
- 安装了 `waitress` 就用它作为生产级 WSGI 服务器（纯 Python，Windows 可用），否则回退到 Flask 自带服务器。
- 清理了无用的导入与函数。

**界面**
- 有未保存修改的页面：离开前确认；关闭标签页前提醒；后台刷新不再覆盖正在编辑的内容；“放弃修改”真正恢复为已保存的值。
- 侧栏显示版本号。

**测试**：80 → 98 个。
